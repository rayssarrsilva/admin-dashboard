## Description
A visual frontend web design of a admin dashboard, it contain:
1. Header, with the profile photo, bio, search bar to find the projects and some buttons for frequently used actions
2. Project area, built to keep all the project you add, which you can: save, share and see
3. Trending area, where it shows some others profiles in the app
4. Announcements, where you see other projects from people you follow
5. Sidebar, with link to things and places you can access

It was build with grid and flexbox, to be somehow responsive when you shrink the web page and access in different devices. The porpuse is to train combining both layouts (grid + flexbox)
